What happens next

  • We inspect the original unit and determine whether the data path is recoverable
  • If recovery is possible, the data can be prepared for a compatible replacement
  • If you also supply a suitable donor TCM, cloning can be arranged
  • If the data cannot be recovered, we explain the result rather than pretending the damaged board is repairable
