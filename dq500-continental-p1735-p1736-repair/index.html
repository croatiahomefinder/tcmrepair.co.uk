DQ500 Continental

Continental DQ500 P1735 / P1736 repair.

Continental DQ500 controllers use a different pressure-sensing architecture from the Bosch version. We identify the actual TCM hardware before repair, then use the correct Continental-compatible components for the supported P1735/P1736 fault.

Other Continental faults

P0607, P0715/P0716 and P0850/P0851 are test-first jobs.

These are real Continental DQ500 repair categories, but they are not one universal component swap. We accept them for free assessment and only confirm a repair after the exact fault path is established.

ODIS + generic diagnostic wording

Continental DQ500 faults can arrive under several code formats.

We use the P-code, VAG/ODIS symptom number and full fault meaning together. This matters particularly for P0607 and speed-signal faults where the symptom number changes the repair route.
